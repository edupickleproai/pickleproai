## 🐛 Troubleshooting

### Node.js Not Found
**Solution**: 
1. Download from https://nodejs.org/ (LTS version)
2. Install and restart terminal
3. Verify: `node --version`

### Port 3000 Already in Use
```powershell
# Find the process
netstat -ano | findstr :3000

# Kill it
taskkill /PID <PID> /F
```

### npm install fails
```bash
# Clear cache
npm cache clean --force

# Remove lock file
rm package-lock.json

# Try again
npm install
```

### ESLint Errors
```bash
# Run ESLint fix
npm run lint -- --fix
```
